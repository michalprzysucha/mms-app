# Create chat room

## User Story

As a Discord server administrator,
I want to create chat rooms for chosen players. Additionally, I want to be able to specify which server roles to add
to the newly created room.

## Scenario: Administrator creates a room 

### **Given** 

- Discord server
- administrator or equivalent role
- players' names
- room name
- roles names to add

### **When**

The administrator creates the room 

### **Then**

The room is created with specified players and roles.
