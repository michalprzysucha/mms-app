# Confirm match results

## User Story

As a player,
I want to confirm the results of a match,
so that the outcome is recorded.

## Scenario: Player confirms match results

### **Given**  

 - Discord server
 - Match results
 - The player has appropriate role on a server

### **When**  

The player confirms the match results

### **Then**  

The match results are confirmed. Players ratings are updated accordingly and the match room is deleted.
